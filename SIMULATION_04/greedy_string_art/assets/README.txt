GREEDY STRING ART - ASSETS FOLDER
====================================

This folder contains static assets for the Greedy String Art simulation.

Structure:
----------
- icons/        : SVG icons for the control panel GUI
- (future)      : Any custom thread textures or backgrounds

Notes:
------
- Upload your target portrait images through the control panel
- Images will be copied to the uploads/ folder
- Supported formats: PNG, JPG, JPEG, BMP
- Recommended: High-contrast grayscale portraits work best
