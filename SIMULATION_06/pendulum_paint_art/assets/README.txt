# Pendulum Paint Art - Assets

This folder contains assets used by the Pendulum Paint Art simulation.

## Icons

The `icons/` subfolder should contain SVG icons for the UI:
- `upload.svg` - Upload button icon
- `clear.svg` - Clear button icon
- `save.svg` - Save button icon
- `settings.svg` - Settings icon

## Adding Custom Assets

You can add custom assets to this folder:
- Custom background textures
- Paint brush textures
- Any other visual assets

## Note

If icons are missing, the UI will still function but without icon decorations.
