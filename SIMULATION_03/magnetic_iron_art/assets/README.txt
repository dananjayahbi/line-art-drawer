# Magnetic Iron Filings Art - Assets Directory

This directory contains assets for the simulation:

## Structure

- `icons/` - SVG icons for the control panel UI
- `magnet_settings.json` - Custom magnet tip position settings
- `custom_magnet.png` (optional) - Custom magnet cursor image

## Custom Magnet

To use a custom magnet cursor:
1. Add your magnet image as `custom_magnet.png` in this folder
2. Enable "Use Custom Magnet" in the control panel
3. Click on the magnet preview to set the tip position

## Icon Requirements

If adding custom icons, use SVG format for best quality at any resolution.
