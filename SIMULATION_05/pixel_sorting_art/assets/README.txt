Pixel Sorting Art Assets
========================

This folder contains assets for the Pixel Sorting Art simulation.

Structure:
---------
icons/          - SVG icons for the control panel UI
custom_pen.png  - Optional custom cursor image

Icons:
------
Place SVG icons in the icons/ folder for the control panel.
Recommended icons:
- upload.svg       - Image upload button
- clear.svg        - Clear/reset button
- folder.svg       - Open folder button
- video.svg        - Generate video button
- play.svg         - Launch simulation button
- settings.svg     - Settings icon
- sort.svg         - Sorting algorithm icon
- glow.svg         - Glow/effects icon
- zoom.svg         - Camera zoom icon

Color Palette:
--------------
Vaporwave theme:
- Primary: #ff00ff (Magenta)
- Secondary: #00ffff (Cyan)
- Accent: #ff6b9d (Pink)
- Background: #1a1a2e

Cyberpunk theme:
- Primary: #00ff00 (Green)
- Secondary: #ffff00 (Yellow)
- Accent: #ff0000 (Red)
- Background: #0a0a0a

All icons should be designed to work well on dark backgrounds.
